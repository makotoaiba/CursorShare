CursorShare
自分の画面と音声を共有し、参加者のマウスカーソルを色付き・名前付きで表示するアプリです。
参加者のカーソル・リアクション・線・チャットは、このPCのデスクトップ上にも重ねて表示されます。
参加者はマイクを使って声でも話せます。
参加者の操作がこのPCに送られることはありません（見るだけ・指し示すだけ・話すだけ）。

■ 使い方（画面を共有する人）
1. CursorShare.exe をダブルクリック（アプリの画面が開きます）
2. 「画面共有を開始」→ 共有する画面を選ぶ
   - 「画面全体」を選ぶと、参加者のカーソルがそのモニターのデスクトップに直接表示されます
   - 「ウィンドウ」を選んだ場合、カーソルはアプリ内のプレビューにだけ表示されます
   - 音声：選択画面を開いたら、共有したい音（Premiere・DAWなど）を再生してください。
     音を拾えたものが自動で選ばれます（バーが動いている行を手で選んでもOK）。
     どれも反応しない時は、音を出しているソフトのオーディオ出力を ASIO から
     Windowsのデバイス（MME / WASAPI）に変えてください。
   - 共有中は上部に共有音のレベルが表示されます（無音が続くと警告が出ます）
3. 参加者にURLを送る
   - 離れた場所の人・マイクを使う人：「インターネット公開」をオン →「インターネット用URLをコピー」
   - 同じ社内/家のネットワークで、見るだけの人：「LAN用URLをコピー」でもOK
   URLは起動ごとに変わります。

デスクトップに重なる表示はクリックを素通りするので、普段どおり作業できます。
この表示は共有映像には映りません。邪魔なときは「デスクトップ表示」をオフに。
離れた人のチャットと「いま話している人」は、デスクトップの右下にも表示されます。

■ 参加者の声（ボイス）
参加者がマイクをオンにすると、その声がこのPCで鳴り、他の参加者にも届きます。
画面共有をしていない間も話せます。
- 上部の「🎧 ボイス」で、声の音量・声を鳴らす再生デバイス（出力先）を変えられます
- 参加者名の横のマイクの印で、誰がオン／ミュート中かが分かります。話している人は緑の枠で光ります
- 参加者名をクリックすると、その人のマイクをミュートできます（本人が解除できます）
- 「全員のマイクをミュート」で一括ミュート

■ ハウリング防止
PCの音を共有していると、このPCで鳴らした参加者の声まで共有音に混ざり、参加者に自分の声が
遅れて返ってハウリングの原因になります。CursorShare は次の順で自動的に防ぎます。
1. Windows 11：共有音から、このアプリが鳴らす音（＝参加者の声）だけを自動で除外します
2. 共有を始めるたびに、ほぼ聞こえない高さの短い確認音を出して、声が共有音に混ざる環境かを実測します
3. 混ざる環境（Windows 10、オーディオインターフェースのループバック入力を共有している時など）では、
   参加者が話している間だけ共有音を止めます（上部に「ハウリング防止」と表示されます）
   → 「🎧 ボイス」の「出力先」を、共有していない別の再生デバイスにすれば、止めずに済みます
「🎧 ボイス」の「ハウリング防止」で、自動／常にオン／オフを切り替えられます（通常は自動のまま）。
ホスト自身のマイクを共有音にしてスピーカーで聞く場合は、ヘッドホンを使うか「常にオン」にしてください。

■ 参加する人
受け取ったURLを Chrome か Edge で開き、名前を入れるだけです。インストール不要。
- カーソルを映像の上に乗せると、全員に自分の色のカーソルが表示されます
- クリックで波紋、映像下のボタンかキー1〜6でリアクション、右側でチャット
- 右クリックしたままドラッグすると、自分の色の線を描けます（約3秒で消えます）。
  「ここからここまで」「この吹き出し」などを指し示すのに使えます
- 「マイクを使う」を押すと声で話せます。もう一度押すとミュート、また押すと解除（V キーでも切り替え）
  ・横の ▾ で、使うマイクの選択と「マイクを切る」
  ・「声」のつまみは、他の参加者の声の音量
  ・マイクはエコーキャンセル付きですが、できればヘッドホンを使ってください
  ・マイクを使えるのは「インターネット用URL」（https）で参加した時だけです。
    LAN用URL（http）では、ブラウザの制限でマイクを使えません（声を聞くことはできます）
- 共有音（ホストのPCの音）のオン/オフは M キー（横のバーで受信中の音量が見えます）

■ 一人で動作確認するとき
アプリで「画面共有を開始」→ このPCのブラウザで参加者用URLを開いて、映像の上でマウスを動かす。
デスクトップ（とアプリのプレビュー）に自分の名前のカーソルが出れば成功です。
同じPCだと、ブラウザが鳴らした音をアプリがまた拾って音が回り続けるので、参加者画面の共有音は
最初オフになっています。マイクも試す時は、ヘッドホンを使うか、「🎧 ボイス」の音量を0にしてください
（スピーカーのままだと、自分の声をマイクが拾い続けてハウリングします）。

■ 初回起動時の注意
- 「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」
  （署名のない自作アプリのため表示されます）
- ファイアウォールの許可を聞かれたら「プライベート ネットワーク」を許可

■ うまくいかない時
- 共有音が届かない：ホストの共有音のレベルが動いているか確認。動かなければ音声の選択を変える。
- 参加者の声が聞こえない：「🎧 ボイス」のバーが動いているか確認。動いていれば音量と出力先を、
  動いていなければ参加者側のマイク（オンになっているか・マイクの選択）を確認。
- 話すたびに共有音が途切れる：ハウリング防止が働いています（上の「ハウリング防止」を参照）。
  マイクを使わない人にはミュートしてもらうと、途切れが減ります。
- 映像が映らない・声が届かない（離れた人）：相手の回線によっては中継サーバー（TURN）が必要です。
  config.json の iceServers に追加してください。
- 映像が粗い・止まる：config.json の videoMaxBitrate を下げてください
  （映像は参加者1人ずつに送るので、上り回線を人数分使います）。
- ポート8787が使用中なら自動で次の番号を使います。

■ config.json（必要な時だけ編集）
  port            … 使うポート番号
  accessKey       … 参加用URLの合言葉。空なら起動ごとにランダム
  videoMaxBitrate … 参加者1人あたりの映像の上限（bps）
  iceServers      … STUN/TURNサーバー
