CursorShare
自分の画面と音声を共有し、参加者のマウスカーソルを色付き・名前付きで表示するアプリです。
参加者のカーソル・リアクション・チャットは、このPCのデスクトップ上にも重ねて表示されます。
参加者の操作がこのPCに送られることはありません（見るだけ・指し示すだけ）。

■ 使い方（画面を共有する人）
1. CursorShare.exe をダブルクリック（アプリの画面が開きます）
2. 「画面共有を開始」→ 共有する画面を選ぶ
   - 「画面全体」を選ぶと、参加者のカーソルがそのモニターのデスクトップに直接表示されます
   - 「ウィンドウ」を選んだ場合、カーソルはアプリ内のプレビューにだけ表示されます
   - 音声：選択画面を開いたら、共有したい音（Premiere・DAWなど）を再生してください。
     音を拾えたものが自動で選ばれます（バーが動いている行を手で選んでもOK）。
     どれも反応しない時は、音を出しているソフトのオーディオ出力を ASIO から
     Windowsのデバイス（MME / WASAPI）に変えてください。
   - 共有中は上部に音声レベルが表示されます（無音が続くと警告が出ます）
3. 参加者にURLを送る
   - 同じ社内/家のネットワーク：「LAN用URLをコピー」
   - 離れた場所の人：「インターネット公開」をオン →「インターネット用URLをコピー」
   URLは起動ごとに変わります。

デスクトップに重なる表示はクリックを素通りするので、普段どおり作業できます。
この表示は共有映像には映りません。邪魔なときは「デスクトップ表示」をオフに。
離れた人のチャットは、デスクトップの右下にも数秒表示されます。

■ 参加する人
受け取ったURLを Chrome か Edge で開き、名前を入れるだけです。インストール不要。
- カーソルを映像の上に乗せると、全員に自分の色のカーソルが表示されます
  （自分の画面では普段のマウスカーソルが見えるので、自分の色付きカーソルは描かれません）
- クリックで波紋、映像下のボタンかキー1〜6でリアクション、右側でチャット
- 音声のオン/オフは M キー（横のバーで受信中の音量が見えます）

■ 一人で動作確認するとき
アプリで「画面共有を開始」→ ブラウザで参加者用URLを開いて、映像の上でマウスを動かす。
デスクトップ（とアプリのプレビュー）に自分の名前のカーソルが出れば成功です。

■ 初回起動時の注意
- 「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」
  （署名のない自作アプリのため表示されます）
- ファイアウォールの許可を聞かれたら「プライベート ネットワーク」を許可

■ うまくいかない時
- 音声が届かない：ホストの音声レベルが動いているか確認。動かなければ音声の選択を変える。
  同じPCで参加者画面も開いて試すと音がループするので、試すときは参加者側をミュートに。
- 映像が映らない（離れた人）：相手の回線によっては中継サーバー（TURN）が必要です。
  config.json の iceServers に追加してください。
- 映像が粗い・止まる：config.json の videoMaxBitrate を下げてください
  （映像は参加者1人ずつに送るので、上り回線を人数分使います）。
- ポート8787が使用中なら自動で次の番号を使います。

■ config.json（必要な時だけ編集）
  port            … 使うポート番号
  accessKey       … 参加用URLの合言葉。空なら起動ごとにランダム
  videoMaxBitrate … 参加者1人あたりの映像の上限（bps）
  iceServers      … STUN/TURNサーバー
