# CursorShare

自分のPC画面（と音声）を共有しながら、参加者のマウスカーソルを **色付き・名前付き** で表示するアプリです（Windows / Mac）。
参加者のカーソルはホストのデスクトップにも重ねて表示されるので、「ここ」「このセリフ」と指し示しながら打ち合わせできます。
参加者の操作がホストのPCに送られることはありません（見るだけ・指し示すだけ）。

## ダウンロード

Windows版とMac版は、別々のリリースとして公開しています。

| PC | リリース | ファイル |
|---|---|---|
| Windows | [Windows版のリリース一覧](../../releases?q=win-v&expanded=true) | `CursorShare-x.x.x-win.zip` → `CursorShare.exe` |
| Mac（Apple シリコン M1〜） | [Mac版のリリース一覧](../../releases?q=mac-v&expanded=true) | `CursorShare-x.x.x-mac-arm64.zip` → `CursorShare.app` |
| Mac（Intel） | [Mac版のリリース一覧](../../releases?q=mac-v&expanded=true) | `CursorShare-x.x.x-mac-x64.zip` → `CursorShare.app` |

参加する人はインストール不要で、ホストから届いたURLを Chrome / Edge で開くだけです。

> 署名のない自作アプリのため、初回は OS に止められます。
> Windows は「詳細情報」→「実行」。Mac は「システム設定」→「プライバシーとセキュリティ」→「このまま開く」（zip 内の README.txt に手順あり）。
> Mac では初回に「画面収録」（PCの音を共有するなら「システムオーディオ録音」も）の許可が必要です。

## できること

- 参加者ごとに色分けされたカーソル（名前ラベル付き）を、共有映像とホストのデスクトップに表示
- デスクトップ表示はクリックを素通りし、共有映像にも映らない
- クリック位置に波紋、リアクション（キー 1〜6）、チャット（カーソル横の吹き出し・デスクトップ右下の通知）
- 右クリックしたままドラッグで、数秒で消える線を描いて指し示せる（ホストのデスクトップにも表示）
- 参加者が弾ける1オクターブの鍵盤（パソコンのキーでも可）。音は全員に届き、弾いた音名（ドレミ / CDE）を表示
- 参加者がマイクで話せるボイス機能（ミュートボタン、ホストからのミュート、発言中の表示）
- ハウリング防止：共有しているPCの音に参加者の声が混ざって相手に返るのを自動で防ぐ
- 音声の共有。共有したい音を鳴らすと、拾えている音源を自動で選択
- 同じLAN内はもちろん、Cloudflare のクイックトンネルで離れた人とも共有（ボタン1つ、ポート開放不要）
- 参加URLには合言葉が付き、起動ごとに変わる

## 使い方

1. `CursorShare.exe` を起動
2. 「画面共有を開始」→ 共有する画面を選ぶ（同時に、共有したい音を鳴らすと音声も自動で選ばれます）
3. 「LAN用URLをコピー」または「インターネット公開」→「インターネット用URLをコピー」で参加者に送る

参加者は「マイクを使う」を押すと声で話せます（マイクを使うのは https の「インターネット用URL」から参加した時だけ。LAN用URL は http のため、ブラウザの制限でマイク不可）。

詳しくは配布 zip 内の `README.txt` を参照してください。

## ハウリング防止の仕組み

PCの音を共有していると、ホストのPCで鳴らした参加者の声まで共有音に混ざり、参加者に自分の声が遅れて返ります。

1. **Windows 11**：`restrictOwnAudio` で、共有音からこのアプリ自身の音（＝参加者の声）を除外
2. 共有開始時に、ほぼ聞こえない高さの短い確認音で、声が共有音に混ざる環境かを実測
3. 混ざる環境（Windows 10、オーディオインターフェースのループバック入力など）では、参加者が話している間だけ共有音を止める。声の出力先を別の再生デバイスにすれば止めずに済む

## 設定（config.json）

| 項目 | 内容 |
|---|---|
| `port` | 使うポート番号（使用中なら自動で次の番号） |
| `accessKey` | 参加URLの合言葉。空なら起動ごとにランダム |
| `videoMaxBitrate` | 参加者1人あたりの映像ビットレート上限（bps） |
| `iceServers` | STUN / TURN サーバー。離れた人の映像が届かない時は TURN を追加 |

## 仕組み

- 映像・共有音：WebRTC でホストから各参加者へ直接送信
- ボイス：参加者のマイクを WebRTC でホストへ。ホストが「その人以外の全員の声」をまとめて各参加者へ返す
- カーソル・チャット：内蔵サーバー（Node.js + WebSocket）が中継
- アプリ本体：Electron。デスクトップ表示は透明・クリック透過・キャプチャ除外のウィンドウ

## 開発

```bash
npm install
npm run app      # アプリ版を起動
npm start        # ブラウザ版（ホスト画面を http://localhost:8787/host で開く）
```

インターネット公開を試すには、`cloudflared.exe` をプロジェクト直下に置いてください。

## リリース手順

Windows版とMac版は、タグの付け方で別々にリリースします（ソースは共通）。

1. `package.json` の `version` を上げてコミット・push
2. 出したい方のタグを付けて push
   - Windows版：`git tag win-v1.4.0 && git push origin win-v1.4.0`
   - Mac版：`git tag mac-v1.4.0 && git push origin mac-v1.4.0`
3. GitHub Actions がビルドし、「Windows版 v1.4.0」「Mac版 v1.4.0」のようなリリースを作ります

タグの番号は `package.json` の `version` と同じにしてください（違うとビルドが止まります）。
片方だけ直した場合は、そちらのタグだけ付ければ大丈夫です。
